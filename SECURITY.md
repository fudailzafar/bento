# Security policy

## Supported versions

Only the latest version on the `main` branch is currently supported.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Open a
private report through
[GitHub's private vulnerability reporting](https://github.com/fudailzafar/portfoliofy-v1/security/advisories/new).

Include:

- A clear description of the vulnerability and its impact.
- Steps to reproduce or a minimal proof of concept.
- The affected route, component, or dependency.
- Any suggested mitigation.

Please allow maintainers reasonable time to investigate and release a fix
before publicly disclosing the issue. Do not include real credentials,
production data, or other sensitive information in a report.
